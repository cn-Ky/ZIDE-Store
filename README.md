# ZIDE Store

Next.js 14 + React Three Fiber + Tailwind + Zustand.

## Çalıştırma

```bash
npm install
npm run dev
# http://localhost:3000
```

## Oynanış

| Tuş | İşlev |
| --- | --- |
| W A S D / ↑ ↓ | Yürü |
| Shift | Koş |
| Fare sürükle / ← → | Kamerayı döndür |
| E | Raftaki oyunu incele / kasada oyunu okut / sepeti aç |
| TAB (veya Q) | Aynı rafta üst-alt / komşu oyun arasında geç |
| R | Elindeki oyunu rafa bırak |
| C | Sepeti aç-kapat |
| ESC | Pencereyi kapat |



## Not:

- Oyunlar ve markalar tamamen kurgusaldır. Gerçeği yansıtmamaktadır.
